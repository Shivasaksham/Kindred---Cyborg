# Kindred – Cyborg landing page

A responsive, single-file landing page for a fictional augmentation clinic.

## Features
- Interactive body scanner with five clickable augmentation sites
- Accessible tabs (arrow-key navigation) for each module
- Organic ↔ augmented slider that live-updates performance stats
- Process timeline, validated booking form
- Responsive down to ~320px, keyboard focus styles, `prefers-reduced-motion` support

## Run
Open `index.html` in a browser. No build step. Fonts load from Google Fonts.

## Deploy on GitHub Pages
Push the repo, then Settings → Pages → Deploy from branch → `main` / root.
